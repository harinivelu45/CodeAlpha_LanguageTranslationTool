🌐 Language Translation Tool 
📌 Project Overview

This project is a simple Language Translation Web App built using Python and Streamlit.
It allows users to enter text and translate it into different languages easily using a translation API.

🚀 Features
✍️ Enter text for translation
🌍 Select target language
⚡ Fast and simple translation
🖥️ User-friendly web interface (Streamlit)
🔄 Supports multiple languages
🛠️ Technologies Used
Python 🐍
Streamlit 🎈
Google Translate API / Deep Translator (or any API you used)

🌐 How it Works
User enters text in input box
Selects target language
Clicks "Translate" button
System returns translated text instantly
